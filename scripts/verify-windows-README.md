# Проверка AirFrame на Windows

1. Распакуйте portable-архив полностью в обычную папку на Windows 10/11 x64.
2. Закройте ранее запущенный AirFrame и дважды нажмите **«Проверить Windows.cmd»**.
3. Пока идёт проверка, оставьте рабочий стол разблокированным и не перекрывайте цветное тестовое окно. Дождитесь `PASSED` или `FAILED` в окне проверки.

Отчёт сохраняется в `%LOCALAPPDATA%\AirFrame\verification\<дата-время>`. Точный путь будет напечатан в конце. Основной результат — `windows-report.json`, подробности — `runtime-report.json` и файлы `.log`. Папку отчёта можно целиком передать для разбора ошибки.

Проверка использует Python и библиотеки из самого архива. Устанавливать Python, запускать установку пакетов или подключать телефон не требуется. Она открывает собственные окна AirFrame, проверяет известные цветные кадры, настройки, локальный H.264-поток и обычный запуск `AirFrame.exe`, затем закрывает только запущенные ею процессы. Сохраняются снимки собственных тестовых окон; полного снимка рабочего стола нет.

Это проверка работоспособности на данном компьютере, а не измерение 60 FPS, реального телефона, Wi-Fi или записи OBS. Windows N требует установленного Media Feature Pack; его отсутствие будет явно указано в отчёте.

Для проверки ZIP с путём, содержащим пробелы и кириллицу, из исходников:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-windows.ps1 -Package .\AirFrame-windows-x64.zip
```

Вариант `-Package` распаковывает архив в отдельную тестовую папку и сохраняет его SHA-256 в отчёте. `ExecutionPolicy Bypass` относится только к запущенному процессу проверки и не меняет постоянные настройки PowerShell.
